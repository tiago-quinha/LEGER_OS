# 01.03 - Database Migrations & Schema Sync

**Layer 1 Directive (SOP)**

## PostgREST Schema Cache Reload Invariant
Whenever modifying PostgreSQL table schemas via `update_schema.py` or direct SQL connection:

```sql
-- MUST end every migration script with:
NOTIFY pgrst, 'reload schema';
```

## Schema Reload Delay
On Supabase Cloud, propagation can take 30-60 seconds. If a `PGRST204` missing column error occurs, perform a hard refresh (`Ctrl + F5` or `Cmd + Shift + R`).
