# SOP - Stripe Payment Integration & Webhook Architecture

## 1. Overview & Native Embedded UI
LEGER_OS leverages **Embedded Stripe Elements & Stripe Webhooks** for seamless worldwide subscription management. All payment screens are rendered natively inside LEGER_OS using **Slide-Up Bottom Sheet Drawers** with dark-mode styling (`#09090b`), sharp borders, mono typography, and Emerald Green accent buttons (`bg-emerald-600`).

Supported payment methods:
- 💳 **Credit / Debit Cards** (Visa, Mastercard, AMEX)
- 🤖 **Google Pay** (1-click automatic on Android/Chrome)
- 🍏 **Apple Pay** (1-click automatic on iOS/Safari)
- 🅿️ **PayPal** (Recurring subscription & sandbox support)
- 🇵🇹 **MB WAY** (Native Portuguese mobile payment for EUR transactions)

## 3. Mandatory Stripe Technical Invariants

1. **Tax-Inclusive Pricing Invariant**:
   - All Stripe Sessions & PaymentIntents MUST specify `tax_behavior: "inclusive"`.
   - The price advertised in the application (e.g. `€4.99`, `€2.50`, `$5.50`, `£4.50`, `¥800`) is **EXACTLY** what the user pays with zero added tax surprises.
   - Stripe Managed Tax automatically calculates and extracts local VAT/IVA (e.g., 23% in Portugal = €0.93 of €4.99) for tax compliance in the background.

2. **Product Tax Code Invariant**:
   - For accounts with Stripe Managed Payments / Auto Tax enabled, all line items MUST include `tax_code: "txcd_10103001"` (SaaS - Electronic Software Subscription).

3. **Stripe API Version Requirement**:
   - Must use `apiVersion: "2025-03-31.basil"` or greater for Managed Payments accounts.

4. **Official Compliance Footer Invariant**:
   - All embedded payment drawers MUST render the official compliance footer:
     - Left: `🔒 256-BIT SSL ENCRYPTED`
     - Right: `POWERED BY stripe` (wordmark in zinc-100 sans font)

## 4. Stripe Dashboard Configuration Guide

1. **Activate Payment Methods**:
   - Go to **Stripe Dashboard $\rightarrow$ Settings $\rightarrow$ Payment Methods**.
   - Enable **Cards**, **Apple Pay**, **Google Pay**, **PayPal**, and **MB WAY**.

2. **Configure Webhook Endpoint**:
   - Add endpoint: `https://legeros.vercel.app/api/stripe/webhook`
   - Select events:
     - `checkout.session.completed`
     - `customer.subscription.created`
     - `customer.subscription.updated`
     - `customer.subscription.deleted`
   - Copy **Signing Secret** (`whsec_...`) into Vercel / `.env` as `STRIPE_WEBHOOK_SECRET`.

3. **Environment Variables**:
   ```env
   STRIPE_SECRET_KEY=sk_live_...
   NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_live_...
   STRIPE_WEBHOOK_SECRET=whsec_...
   ```
