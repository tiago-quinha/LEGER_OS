# 01.17 - Native Mobile Architecture & Capacitor Android APK Build SOP

## Purpose & Scope
This Standard Operating Procedure establishes the engineering standards, native plugin architecture, permission models, and build workflows for converting LEGER_OS into native Android (`.apk` / `.aab`) and iOS binaries via Capacitor with 100% code reuse and zero UI rewrites.

---

## 1. Native Mobile Architecture & Shell

LEGER_OS utilizes **Capacitor 8** by Ionic to package the Next.js frontend into hardware-accelerated native webviews:
- **Zero UI Rewrites**: 100% of React 19 components, Tailwind CSS styling, Recharts, and Framer Motion gestures run natively at 60 FPS.
- **Theme & Status Bar Invariant**: Native status bar and splash background are locked to `#09090b` with `style: "DARK"` in `capacitor.config.ts`.
- **Live Server Synchronization**: Points dynamically to `https://leger-os.vercel.app` (or custom host) so user interfaces update instantly without requiring full App Store reviews for web updates.

- `android.permission.READ_MEDIA_IMAGES`
- `android.permission.RECEIVE_BOOT_COMPLETED` & `WAKE_LOCK`
- `android.permission.QUERY_ALL_PACKAGES` (Dynamic installed apps detection)

## 3. Native Services & Custom Capacitor Bridges

### 1. `LegerBankNotificationListenerService.java`
- Extends `android.service.notification.NotificationListenerService`.
- Listens for incoming payment/card push banners from user-monitored banking packages.
- Bypasses third-party automation tools (MacroDroid) to send direct asynchronous HTTP requests to `/api/transactions/device-push`.
- Filtered dynamically via `SharedPreferences` (`"selected_bank_packages"`).

### 2. `LegerBankSyncPlugin.java`
- Custom Capacitor Plugin registered in `MainActivity.java`.
- Methods:
  - `getInstalledApps()`: Queries `PackageManager` for installed apps and detects financial services.
  - `getSelectedBankPackages()` / `setSelectedBankPackages()`: Manages dynamic monitoring list.
  - `isNotificationAccessGranted()`: Checks if the user has enabled Notification Access in Android settings.
  - `openNotificationAccessSettings()`: Opens Android's system Notification Access screen with 1 tap.

### 3. 100+ Curated Banking & Fintech Registry (`src/lib/banking-apps-registry.ts`)
- Curated presets covering Portugal (Santander, MB WAY, CGD, Millennium, ActivoBank, etc.), Spain (BBVA, CaixaBank, Sabadell), UK (Revolut, Monzo, Starling, Barclays), Europe (N26, Wise, Trade Republic, Klarna), US (Chase, BoA, Wells Fargo, Amex), and LATAM (Nubank, Itaú, Inter).

## 4. Build & Distribution Workflow

### Commands
1. **Sync Web Assets & Plugins**:
   ```bash
   npm run cap:sync
   ```
2. **Open in Android Studio**:
   ```bash
   npm run cap:android
   ```
3. **Generate Standalone APK**:
   - In Android Studio: **Build $\rightarrow$ Build Bundle(s) / APK(s) $\rightarrow$ Build APK(s)**.
   - Output binary: `android/app/build/outputs/apk/debug/app-debug.apk`.

### User Activation (1-Time Setup on Phone)
1. Install `app-debug.apk` on phone (Allow unknown sources if prompted).
2. Open LEGER_OS $\rightarrow$ **Settings $\rightarrow$ Device Sync**.
3. Tap **Grant Access** to allow Notification Access in Android settings.
4. Select your active banking apps from the detected list.
