# 01.15 - Sovereign Data Portability & Vault Backup SOP

## Objective
Guarantee 100% user data sovereignty through 1-click offline backup downloads (`.json`), spreadsheet-ready table exports (`.csv`), and safe non-destructive restoration with automatic deduplication.

---

## 1. Export Architecture (`/api/user/export`)

The export route provides 3 deterministic download formats:

### A. Full Vault Snapshot (`?format=json&type=vault`)
Returns a complete, human-and-machine-readable JSON bundle containing all database records linked to `user_id`:
```json
{
  "version": "1.0",
  "mainframe": "LEGER_OS",
  "exportedAt": "2026-08-18T...",
  "user": { "id": "...", "email": "..." },
  "vault": {
    "profile": { ... },
    "categories": [ ... ],
    "budgets": [ ... ],
    "expenses": [ ... ],
    "incomes": [ ... ],
    "balances": [ ... ],
    "merchant_rules": [ ... ],
    "portfolio_assets": [ ... ],
    "portfolio_snapshots": [ ... ]
  }
}
```

### B. Ledger Transactions CSV (`?format=csv&type=transactions`)
Returns spreadsheet-ready CSV with columns:
`ID, Date, Merchant, Amount, Category, Category_ID, Raw_Text`

### C. Portfolio Holdings CSV (`?format=csv&type=portfolio`)
Returns spreadsheet-ready CSV with columns:
`ID, Symbol, Name, Asset_Class, Quantity, Average_Buy_Price, Currency`

---

## 2. Safe Restore & Deduplication Protocol (`/api/user/restore`)

The restore engine accepts a `.json` backup file and safely merges records:

1. **Category Mapping**: Maps previous `category_id` references to existing user categories by name (case-insensitive) or creates missing categories automatically.
2. **Budget Upsert**: Upserts category allocations without creating orphaned rows.
3. **Transaction Deduplication**: Computes unique fingerprint `${date}_${merchant}_${amount}` against existing user transactions. Only non-existent records are batch inserted in chunks of 100.
4. **Income & Balance Snapshots**: Restores historical paycheck dates and net worth snapshots.
5. **Portfolio Assets**: Restores active holdings and asset allocations.
6. **AI Journal & Overrides**: Merges conversational memories and stored burn overrides.

* **Placement**: Located in the **Account** tab of `SystemSettingsModal.tsx` and the `General` tab of `SystemConfigView.tsx`.
* **Visuals**: Sharp `#09090b` cards, `rounded-none`, monospaced typography, `SOVEREIGN` security badge, Lucide icons (`Database`, `Download`, `FileSpreadsheet`, `Upload`).
