# 01.06 - Smart Proactive AI Pill Banner Protocol

## Executive Overview
The Proactive AI Pill Banner in `LegerAIAssistant.tsx` serves strictly as an **empirical telemetry detector**. It must ONLY surface real, calculated financial data points from live DB and client state.

## Mandatory Directives

1. **Empirical Telemetry Detection Only (No Fake Suggestions)**:
   - ALL banner texts must be derived from live, empirical numbers:
     - Uncategorized transactions count (`unclassified > 0`)
     - Projected surplus/deficit (€ amount)
     - Spending velocity multiplier (e.g. `1.25x`)
     - Safe daily spend pace limit (€/day)
     - Paycheck countdown (`daysElapsed` / `daysLeft`)
     - Net cash flow delta (€ total in vs out)
     - Top & lowest spend categories (actual category name & € spend)
     - Active routine overrides & active memories
     - Target budget consumption percentage
     - Recent transaction merchant name & exact amount
   - **Banned**: Vague speculative text ("Spot spending anomalies...", "Run AI Cleanse..."), promotional prompts, or non-data suggestions.

2. **AI-Initiated Chat Opening**:
   - Clicking the pill banner opens a fresh chat session with an AI Assistant message (`sender: "assistant"`).
   - Never insert a user auto-prompt (`sender: "user"`).

3. **Multi-Tenant Generic Wording**:
   - Ban hardcoded tenant names (e.g., "Deloitte", "Santander").
   - Use generic terms: "next paycheck", "bank statement extract", "paycheck cycle".

4. **Event-Driven & Token-Efficient Auto-Expansion**:
   - Immediate auto-expansion occurs ONLY during high-priority events:
     - Uncategorized transactions > 0
     - Spending velocity > 1.25x
     - Target budget burn > 85%
   - Routine route visits use a 35% probability check throttled to max once per 3 minutes to avoid API token waste and user fatigue.

5. **Minimal UI / No Emoji Rule**:
   - Zero decorative emojis in AI banner titles or system prompt headers.

6. **Multiple Chat Session Architecture (30-Day Lifetime)**:
   - Sessions are persisted locally in `localStorage` under `leger_chat_sessions_${userId}`.
   - Each session adheres to the `ChatSession` model (`{ id, title, createdAt, updatedAt, messages }`).
   - Sessions older than 30 days (`now - updatedAt > 30 * 24 * 60 * 60 * 1000`) are automatically pruned on load and save.
   - Users can create new sessions (`+ New Chat`), browse past conversations, and delete individual sessions from the in-drawer history panel.

7. **Instant Session Creation on Pill Click**:
   - Clicking an AI pill banner creates a new, dedicated `ChatSession` with the banner topic as the title.
   - Immediately dispatches the empirical financial query to the new session.

8. **Database Query Sanitizer Invariants**:
   - All server-side DB query sanitation (`sanitizeDbQuery` in `/api/leger-ai/query`) must ensure column arrays (`validCols`) remain strictly typed arrays before joining to prevent `TypeError: selectCols.join is not a function`.

9. **Chat History Drawer Overlay & Normalized FAB Standard**:
   - **Full Coverage**: The chat history overlay must match the exact dimensions of the drawer container (`absolute inset-0 bg-card z-30`) to prevent background chat bleeding.
   - **Header Controls**: Header must contain an icon-only `+` (`Plus`) new chat button, `[History]` history toggle, and `[X]` close button.
   - **Bottom-Right FAB**: Within the chat history overlay, the "+ New Chat" action is styled as a white rounded-xl floating action button (`absolute bottom-5 right-5 z-40 h-11 w-11 rounded-xl bg-white text-black shadow-2xl`) matching the established application FAB standard.
   - **Always-Visible Trash Icon**: Delete buttons on session cards must remain consistently visible (`p-2 text-muted-foreground/60 hover:text-destructive`) without hover-only opacity restrictions to ensure seamless mobile touch usability.
   - **Normalized Deletion Confirmation**: Deleting a session triggers an in-app confirmation modal with `#09090b` dark styling, backdrop blur, descriptive session title prompt, and clear `Cancel` / `Delete` actions.
