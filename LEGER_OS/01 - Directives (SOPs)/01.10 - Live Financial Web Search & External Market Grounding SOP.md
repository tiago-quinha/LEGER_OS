# 01.10 - Live Financial Web Search & External Market Grounding SOP

## Purpose & Scope
This Standard Operating Procedure defines the architecture and operational requirements for real-time external financial web search grounding inside the **LEGER_OS** natural language intelligence engine (`Leger AI`).

---

## 1. Grounding Architecture & Workflow

1. **Two-Stage Intent Routing (`src/app/api/leger-ai/query/route.ts`):**
   - When a user query is received, the intent analyzer checks if the query involves external economic, market, or merchant data (`requiresWebSearch: true`).
   - Generates a concise search query `webSearchQuery` (e.g., *"ECB current deposit interest rate 2026"*, *"Spotify price increase Portugal 2026"*, *"Euribor 3-month rate"*).

2. **Web Search Grounding Engine (`src/lib/web-search.ts`):**
   - Calls `searchFinancialWeb(query)`.
   - Extracts top title, URL, clean snippet text, and source domain.
   - Formats a strict `LIVE EXTERNAL WEB SEARCH RESULTS (REAL-TIME GROUNDING)` block for prompt injection.
   - Caches search responses with 1-hour revalidation to eliminate rate limits and preserve speed.

3. **Response Payload Invariants:**
   - The query endpoint returns:
     ```json
     {
       "message": "Direct, data-backed synthesis...",
       "suggestedQueries": ["...", "...", "..."],
       "webSearched": true,
       "webSearchQuery": "...",
       "webSources": [
         { "title": "...", "snippet": "...", "url": "...", "source": "..." }
       ]
     }
     ```

---

## 2. Thinking Telemetry & UI Standards

1. **Dynamic Thinking Telemetry (`ThinkingIndicator` in `LegerAIAssistant.tsx`):**
   - If user query contains market or search keywords (*"ecb", "euribor", "rate", "interest", "stock", "crypto", "price", "inflation", "why did X increase"*), the thinking animation immediately activates external web indicators:
     - `"Searching the financial web..."`
     - `"Grounding live market telemetry..."`
     - `"Cross-referencing verified sources..."`
     - `"Analyzing spending velocity..."`

2. **Grounded Source Badges:**
   - When `webSearched === true` and sources exist, render a subtle, non-intrusive badge:
     `[ 🌐 Grounded with Live Web Search (X sources) ]`
   - Render clickable source chips with external link icons (`ArrowUpRight`).

---

## 3. Proactive Rules & Invariants
- **No Hallucinated Market Figures:** External macroeconomic queries must never guess interest rates or inflation numbers without live search grounding.
- **Provider Agnostic:** Grounding works seamlessly across all configured AI providers (Gemini, OpenAI, Groq, local Ollama).
