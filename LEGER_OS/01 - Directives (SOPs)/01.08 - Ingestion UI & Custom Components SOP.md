# 01.08 - Ingestion UI & Custom Components SOP

**Layer 1 Directive (SOP)**

## Objective
Standardize the Ingest UI pipeline (`/expenses?tab=ingest`), statement preview table ergonomics, custom mainframe control components, and PRO gating standards across LEGER_OS.

---

## 1. Statement Ingestion UI Architecture (`ExpensesView.tsx`)

### Dropzone & Text Area Controls
- **Dual Input Modes**: Native drag & drop zone (`.pdf`, `.txt`, `.csv`, `.json`) + raw text paste area.
- **Upload Icon**: Clean, monochrome icon (`<Upload className="h-6 w-6 text-muted-foreground/70 mb-2 stroke-[1.5]" />`) positioned inside the file dropzone box above the primary label.
- **Explicit Button Parsing Invariant**: Typing text inside the text paste area updates local state **ONLY**. Auto-parsing on typing is strictly banned. Text parsing is triggered **EXCLUSIVELY** when the user clicks **`Parse Text`**.
- **No Sample Feature Invariant**: Sample statement buttons are completely removed to maintain clean, authentic user statement ingestion.

---

## 2. Neural AI Smart Parse PRO Gating
- **Action Button Styling**: `AI Smart Parse` retains permanent Emerald Green PRO theme styling (`bg-emerald-500/10 border border-emerald-500/30 text-emerald-500 hover:bg-emerald-500/20`) with ✨ Sparkles icon.
- **Vertical Alignment**: Icon and label text use `flex items-center justify-center gap-1.5 leading-none` for 100% vertical cross-axis alignment.
- **PRO Access Gate**: Non-PRO users clicking `AI Smart Parse` are presented with a PRO toast and automatically routed to the native slide-up subscription drawer (`setSettingsActiveTab("pro")`).

---

## 3. Statement Preview Table Ergonomics

### Layout & Responsiveness
- **Fixed Proportional Layout**: Container uses `table-fixed` to prevent horizontal scrollbars and eliminate column clipping.
  - Checkbox Column: `w-7`
  - Date Column: `w-14` / `w-16` (`whitespace-nowrap`)
  - Category Column: `w-24` / `w-28`
  - Amount Column: `w-20` / `w-24` (`text-right whitespace-nowrap`)
  - Merchant Column: Fills remaining horizontal space with clean `truncate`.

### Sub-Pixel Flush Floating Header
- Table header (`DATE`, `MERCHANT`, `CATEGORY`, `AMOUNT`) uses `sticky top-[-1px] z-30 bg-card border-b border-border` to remain 100% frozen at the top with zero sub-pixel gaps when scrolling.
- Native `<th>` elements are used for header cells (`p-2 text-left align-middle`).

---

## 4. Custom Mainframe Checkbox Component (`src/components/ui/checkbox.tsx`)

- **Design System Alignment**: Custom square component (`rounded-none`, `border border-border/80`, `bg-foreground text-background` when checked) with bold `<Check className="h-3 w-3 stroke-[3]" />` icon.
- **App-Wide Usage**: All selection inputs across tables, forms, and dialogs MUST use `<Checkbox />` instead of standard browser native inputs.

---

## 5. Authentic Supabase Category Query
- Statement preview dropdowns MUST query the authenticated user's real Supabase categories (`.from("categories").select("*").eq("user_id", user.id).order("name")`).
- Never rely on fake mock categories or static system overrides when user categories exist.
