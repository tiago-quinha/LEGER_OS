# 01.07 - Portfolio & Market Data Engine SOP

## Executive Overview
The **LEGER_OS Portfolio & Asset Management System** enables users to track multi-asset holdings (Stocks, ETFs, Cryptocurrencies, Cash Savings, Commodities, and Custom Positions) alongside their liquid bank account balances. It calculates true total net worth, unrealized PnL returns, asset class allocations, and historical daily valuation snapshots.

---

## 1. Database Schema & RLS Security Invariants

The system operates on two dedicated PostgreSQL tables managed via Supabase PostgREST:

### `portfolio_assets` Table
- `id`: UUID PRIMARY KEY DEFAULT `gen_random_uuid()`
- `user_id`: UUID REFERENCES `auth.users(id)` ON DELETE CASCADE
- `asset_name`: TEXT NOT NULL
- `symbol`: TEXT (e.g. `AAPL`, `VWCE.DE`, `BTC`, `ETH`, `GOLD`)
- `asset_type`: TEXT CHECK IN (`stock_etf`, `crypto`, `cash_equivalent`, `commodity`, `other`)
- `quantity`: NUMERIC(18, 8) NOT NULL DEFAULT 0
- `buy_price`: NUMERIC(14, 2) NOT NULL DEFAULT 0 (Cost basis per unit)
- `current_price`: NUMERIC(14, 2) NOT NULL DEFAULT 0 (Current market unit price)
- `currency`: TEXT NOT NULL DEFAULT 'EUR'
- `institution`: TEXT (Broker/Wallet name, e.g. `Trading 212`, `Degiro`, `Kraken`, `Santander`)
- `notes`: TEXT

### `portfolio_snapshots` Table
- `id`: UUID PRIMARY KEY DEFAULT `gen_random_uuid()`
- `user_id`: UUID REFERENCES `auth.users(id)` ON DELETE CASCADE
- `snapshot_date`: DATE NOT NULL DEFAULT CURRENT_DATE
- `total_net_worth`: NUMERIC(14, 2) NOT NULL
- `liquid_cash`: NUMERIC(14, 2) NOT NULL
- `invested_capital`: NUMERIC(14, 2) NOT NULL
- `total_gain_loss`: NUMERIC(14, 2) NOT NULL
- `asset_breakdown`: JSONB NOT NULL DEFAULT `'{}'::jsonb`
- `UNIQUE(user_id, snapshot_date)`

### Security Policy (RLS)
Both tables MUST enforce strict Row Level Security policies (`auth.uid() = user_id`). Users can only query, insert, update, or delete their own assets.

### PostgREST Cache Invariant
All migration scripts and schema changes MUST end with:
```sql
NOTIFY pgrst, 'reload schema';
```

## 2. Multi-Provider Market Data Integration (Zero-Cost API Architecture)

To fetch market prices without paid enterprise API subscriptions, LEGER_OS leverages serverless public API providers via `/api/portfolio/market-data`:

1. **Stocks & European ETFs**:
   - Provider: **Yahoo Finance API** (`https://query1.finance.yahoo.com/v8/finance/chart/{ticker}`)
   - Coverage: US Equities (`AAPL`, `MSFT`), European ETFs (`VWCE.DE`, `IWDA.AS`, `SWRD.L`), Index Funds, Commodities (`GLD`).
2. **Cryptocurrencies**:
   - Provider: **CoinGecko API** (`https://api.coingecko.com/api/v3/simple/price`)
   - Mapped Symbols: `BTC` -> `bitcoin`, `ETH` -> `ethereum`, `SOL` -> `solana`, `ADA` -> `cardano`, `XRP` -> `ripple`, etc.
3. **Fiat Currency Rates**:
   - Provider: **Frankfurter API** (`https://api.frankfurter.app/latest`)
   - Official European Central Bank (ECB) exchange rates to convert USD/GBP quotes to user base currency (EUR).

## 3. Server Caching & User Rate Limit Safeguards

To prevent rate-limit bans and ensure zero host API costs:

- **15-Minute Server Cache**: Prices fetched from market providers are cached in memory for 15 minutes (`CACHE_TTL_MS = 15 * 60 * 1000`). Repeated page views inside 15 minutes trigger 0 external API calls.
- **Per-User Throttle Limit**: Force market sync triggers are rate-limited to **1 request per 30 seconds** per user ID (`USER_THROTTLE_MS = 30 * 1000`).
- **Core Free Tier Asset Limit**: Core Free users are limited to **15 assets maximum**. LEGER_OS PRO users enjoy unlimited portfolio asset tracking.

## 4. Mathematical Standards & Formulas

1. **Total Invested Capital**:
   $$\text{Invested} = \sum_{i} (\text{quantity}_i \times \text{buy\_price}_i)$$
2. **Total Portfolio Valuation**:
   $$\text{Portfolio Valuation} = \sum_{i} (\text{quantity}_i \times \text{current\_price}_i)$$
3. **Unrealized Gain / Loss (PnL)**:
   $$\text{Total PnL} = \text{Portfolio Valuation} - \text{Invested}$$
   $$\text{PnL \%} = \left( \frac{\text{Total PnL}}{\text{Invested}} \right) \times 100$$
4. **True Total Net Worth**:
   $$\text{Total Net Worth} = \text{Liquid Bank Balance} + \text{Portfolio Valuation}$$

## 5. PRO Tier Monetization & Gating Standards

- **Free Tier (`LEGER_OS Core`)**: Manual asset creation, holding lists, asset class filter tabs, total net worth calculation.
- **PRO Tier (`LEGER_OS PRO`)**: Unlimited asset tracking, automatic live market price sync, AI Neural Yield Simulations, and Volatility Value-at-Risk (VaR) Audits.
- Locked PRO sections MUST be masked cleanly using `<ProLockOverlay />` with backdrop blur (`bg-background/95 backdrop-blur-md`).
- Non-PRO cards MUST use neutral monochrome styling (`text-muted-foreground bg-card border-border`). Emerald Green is strictly reserved for PRO badges and active PRO indicators.
