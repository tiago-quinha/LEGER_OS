# SOP - System Monetization & Design Standards

## 1. Emerald PRO Branding & Non-PRO Color Invariant
- **Emerald Green Exclusivity**: Reserve Emerald Green (`text-emerald-500`, `bg-emerald-500/10`, `border-emerald-500/30`) strictly for **PRO / Premium** features, lock badges, and upgrade cards.
- **Monochrome Non-PRO Utilities**: Non-PRO security/privacy indicators (e.g., Privacy Safe-Deposit mode, floating AI trigger lock badge, security status tags) MUST use neutral monochrome styling (`text-muted-foreground bg-card border-border`).

## 2. Standardized `ProLockOverlay` Component
- All locked PRO features across all views (AI Ingestion, AI Chat Drawer, Projection Graph, Cycle Forecast Card, Settings Modal PRO controls, Phone Webhook Sync) MUST be masked cleanly using the standard `<ProLockOverlay />` component.
- On chart/graph overlays, wrap `ProLockOverlay` in an opaque/blurred `bg-background/95 backdrop-blur-md` backdrop so underlying data is completely non-interactive and hidden.

## 3. No Pseudo-Terminal Underscore Typography Invariant
- Ban pseudo-terminal uppercase underscore jargon in UI copy (e.g., `PRO_ACTIVE`, `CORE_FREE`, `PRO_LOCKED`, `HTTP_403_DENIED`, `SECURITY_GATEKEEPER`, `SUPER_USER`).
- Always use clean, professional natural English typography (e.g., `PRO Active`, `Core Free`, `PRO Locked`, `Access Forbidden`, `Security & Permissions`).

## 5. Proprietary AI Model Copy Invariant (Legal & SLA Protection)
- **No Third-Party Model Naming in Public Copy**: Avoid hardcoding third-party model names (e.g., `Gemini 2.5 Pro`, `GPT-4o`) in public feature bullets, PRO conversion cards, or user-facing footers.
- **Abstracted AI Capability Terminology**: Use clean proprietary terminology (e.g., `AI Neural Ingestion & Categorization`, `AI Processing Engine`, `AI Intelligence Node`). Third-party model names are strictly restricted to technical settings dropdown options (e.g. custom API key setup).

## 6. Dynamic Localized PRO Pricing Engine
- **Base Pricing Anchor**: Base PRO subscription price is anchored at **4.99 EUR** (`EUR: €4.99/mo`).
- **Clean Consumer Rounding**: All supported currency conversions are mapped to clean `.50` or `.00` consumer pricing via `getProPrice(currencyCode)` in `@/lib/format`:
  - `EUR`: **€4.99/mo**
  - `USD`: **$5.50/mo**
  - `GBP`: **£4.50/mo**
  - `BRL`: **R$29.50/mo**
  - `CAD`: **C$7.50/mo**
  - `AUD`: **A$8.50/mo**
  - `JPY`: **¥800/mo**
  - `CHF`: **CHF4.50/mo**
- **Dynamic Lock Gates**: All `<ProLockOverlay />` gates and settings subscription cards must query `getProPrice(userCurrency).formatted` dynamically so prices automatically adapt when the user toggles base currency.
