# SOP - System Settings UI UX & Localized Pricing

## 1. System Settings Drawer Component Architecture
- **Draggable Drawer Mechanics**: `SystemSettingsModal` uses Framer Motion bottom sheet physics with top drag handle bar (`w-16 h-1.5`, `py-3.5`).
- **Direct Navigation**: System / Config buttons open `SystemSettingsModal` directly without showing intermediate popup dialogs or loading flashes.
- **Tab Bar Layout**: Standard tabs include `General`, `AI Engine`, `Rules`, `Phone`, `PRO`, `Account`, and optional `Dev` (Super Users).

## 2. Tab Layout & Responsive Alignment Directives
- **General Preferences Tab (Side-by-Side Invariant)**:
  - Input pairs (`Privacy` $\leftrightarrow$ `Theme`, `Paycheck` $\leftrightarrow$ `Monthly`, `Currency` $\leftrightarrow$ `Language`, `Income` $\leftrightarrow$ `Spend`) MUST use an unconditional 2-column grid (`grid-cols-2 gap-3`) so related options sit side-by-side without vertical stacked bloat.
- **PRO Subscription Tab (Conversion Hero Invariant)**:
  - Must use a full-width high-conversion PRO Hero showcase card (`border-2 border-emerald-500/50 shadow-[0_0_25px_rgba(16,185,129,0.12)]`) with a `RECOMMENDED` badge, price tag, 2-column feature checklist, and prominent Emerald CTA button (`Upgrade to PRO`).
  - Core Base plan sits below the PRO hero card as a full-width subtle status row (`€0/mo`).
  - DO NOT split PRO and Core into side-by-side cards.
- **Account & Security Tab (Stacked Invariant)**:
  - `Session Node` card and `Right to Erasure (GDPR)` card MUST be stacked as full-width vertical rows.

## 3. Localized Currency Pricing Engine (`getProPrice`)
- Baseline subscription price: **4.99 EUR** (`EUR: €4.99`).
- Map of rounded consumer pricing per supported currency:
  - `EUR` $\rightarrow$ `€4.99`
  - `USD` $\rightarrow$ `$5.50`
  - `GBP` $\rightarrow$ `£4.50`
  - `BRL` $\rightarrow$ `R$29.50`
  - `CAD` $\rightarrow$ `C$7.50`
  - `AUD` $\rightarrow$ `A$8.50`
  - `JPY` $\rightarrow$ `¥800`
  - `CHF` $\rightarrow$ `CHF4.50`
- Helper function `getProPrice(currencyCode)` in `@/lib/format` calculates formatted strings dynamically for all lock overlays and settings pricing badges.
