# 01.14 - Conversational AI Intelligence & Anti-Laziness Architecture SOP

## Purpose & Scope
This Standard Operating Procedure defines the system prompt engineering standards, intent query routing, model fallback chains, error shielding protocols, and conversational calibration rules for LEGER_OS's conversational intelligence bridge (`src/app/api/leger-ai/query/route.ts` and `src/components/LegerAIAssistant.tsx`).

---

## 1. Model Fallback & Provider Cascade (`src/lib/ai-bridge.ts`)

1. **Active Gemini Model Pool:**
   - **Primary Model:** `gemini-3.5-flash-lite` (High-throughput, ultra-low latency, optimized for free-tier quotas).
   - **Fallbacks:** `gemini-2.5-flash-lite` $\rightarrow$ `gemini-2.5-flash` $\rightarrow$ `gemini-2.5-pro`.
   - **Legacy Models Barred:** `gemini-1.5-pro`, `gemini-1.5-flash`, and unmaintained 2.0 experimental endpoints are permanently barred.

2. **Multi-Provider Support:**
   - **Groq:** `llama-3.3-70b-versatile` (free 300+ tok/s high-speed inference).
   - **Ollama:** Local offline inference at `http://localhost:11434` (`qwen2.5:7b`, `llama3.2:3b`, `deepseek-r1:8b`).
   - **OpenAI:** `gpt-4o-mini`.

---

## 2. Exhaustive Quantitative Breakdown & Portfolio Audit Invariant

1. **The "Parrot & Deflect" Trap Banned:**
   - The AI must **NEVER** output generic 2-paragraph summaries, macroeconomic filler fluff (*"Scanning live financial markets...", "Global equities remain on an upward path..."*), or ask lazy follow-up questions to postpone work (*"Would you like me to examine specific holdings?"*).
   - All calculations, matrices, and analyses must be delivered **exhaustively and upfront**.

2. **Mandatory Portfolio & Multi-Asset Audit Protocol:**
   - When asked to analyze, review, or assess the portfolio, stocks, crypto, or capital deployment:
     - **Holdings & Allocation Matrix (Table):**
       `| Ticker | Asset Name | Type | Qty | Invested Basis (€) | Current Value (€) | P&L (€ / %) | Weight (%) |`
       *(Invariant: Invested Basis MUST be $\text{Qty} \times \text{Buy Price}$, summing to Total Invested Capital).*
     - **Thematic & Sector Exposure Audit:** Sub-sector capital distribution (Enterprise AI, Cloud Infra, Big Tech, Crypto) and concentration risks.
     - **Holding-by-Holding Fundamentals & Catalysts:** Direct, holding-specific analysis incorporating live financial search grounding (earnings, contracts, hardware architectures).
     - **Liquidity Alignment & Deployment Headroom:** Ratio of invested assets vs available liquid cycle reserves and remaining monthly investment budget headroom.

3. **Mandated Immediate Analytical Structure for Cash Flow & Budgets:**
   - When the user asks for a *breakdown*, *comparison*, *audit*, *analysis*, or *income vs expenses*:
     - **Inflows Section:** Itemized deposits, source/employer names, dates, and amounts.
     - **Outflows & Category Variance Matrix (Table):** Category Name, Spent (€), Budget Limit (€), % Utilized, Variance (€ Over/Under).
     - **Top Merchant Drivers & Anomaly Leaks:** Specific merchants driving outflow spikes.
     - **Net Velocity & Daily Variable Burn:** Empirical variable daily burn rate (€/day) using recency decay ($\lambda = 0.12$).
     - **Closing Balance Projection:** Exact forecasted close balance.

## 3. UI Markdown & Heading Typography Standards (`renderFormattedText`)

1. **Universal Heading Parsing (`#{1,6}`):**
   - The client-side markdown renderer in `LegerAIAssistant.tsx` parses all heading levels (`#` through `######`) via `/^(#{1,6})\s+(.*)$/`.
   - All headings render using the standard LEGER_OS title typography: `font-sans font-bold tracking-tighter uppercase text-foreground` with a clean underline rule (`border-b border-border/40 pb-1`).
2. **Inline Code & Text Formatting:**
   - Inline code (`` `code` ``) renders with `font-mono text-[10px] bg-secondary/80 border border-border/40`.
   - Bold (`**text**`) renders with `font-bold text-foreground`.
   - Markdown tables render inside responsive `border border-border/80 rounded bg-secondary/10 font-mono text-[10px]` containers.

## 4. Conversational Calibration & Fragment/Typo Invariant

1. **The "Unprompted Telemetry Dump" Trap Banned:**
   - If the user sends a greeting (`"hi"`), acknowledgment (`"ok"`), or incomplete fragment/typo (`"rea"`, `"asdf"`, `"..."`), the AI must **NOT** dump full financial telemetry or wall-of-text statistics.

2. **Calibrated Response Protocol:**
   - **Greetings:** Warm, polite 1-sentence welcome asking how to assist with ledger, radar, portfolio, or budgets.
   - **Fragments / Typos:** Short 1-sentence clarification (e.g., *"Did you mean 'recurring', 'real balance', or a specific transaction? How can I assist you?"*).
   - **Full Telemetry Reports:** Generated strictly when a genuine financial query or analysis is requested.

---

## 5. End-User Error Shielding & Super-User Debugging

1. **Regular End-Users:**
   - All raw API errors, 429 quota codes, and stack traces are completely shielded.
   - **On Rate Limits (429):** *"The AI assistant is temporarily experiencing high request traffic. Please try asking again in a moment."*
   - **On Server/Model Errors:** *"I'm currently unable to complete this analysis. Please try asking again in a moment."*
   - **On Timeouts:** *"The request took a little too long to respond. Please try asking again."*

2. **Super-Users (`isSuperUser = true` / Admin / Dev):**
   - Displays clear error status plus a dedicated debug tag:
     `⚠️ Rate Limit Exceeded (429)`
     `[Super User Debug: GoogleGenerativeAI Error: 429 Resource Exhausted]`

---

## 6. Financial Data Integrity Invariants

1. **Paycheck Cycle Grounding:** Analysis is anchored to the active paycheck cycle timeline (`cycleStartDate` $\rightarrow$ `cycleEndDate`), never naive calendar months.
2. **Broker & Investment Neutrality:** Outflows to investment brokers (`XTB`, `DEGIRO`, `TRADE REPUBLIC`, `BINANCE`, `KRAKEN`) or internal savings accounts are balance-neutral asset transfers, never lifestyle spending burn.
3. **Non-Linear Recency Decay Burn:** Future spending models utilize the empirical variable daily burn rate with exponential recency decay ($\lambda = 0.12$), isolating 1-off statistical anomalies and fixed subscriptions.
4. **Anti-Slop Standard:** Prohibits patronizing life-coach platitudes; grounds every response in hard mathematical ratios.
