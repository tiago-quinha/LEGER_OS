# 01.09 - Real-Time Device Push & Bank Notification Sync SOP

**Layer 1 Directive (SOP)**

## Objective
Standardize real-time device transaction capture across Android native notifications, Apple iOS Shortcuts, and developer webhooks (MacroDroid/Tasker) without relying on high-cost, fragile third-party bank aggregators (Plaid/GoCardless).

---

## 1. Unified Production Endpoints

- **Primary Route**: `/api/transactions/device-push`
- **Mobile SDK Alias**: `/api/transactions/mobile-sync`
- **Development/Legacy Bridge**: `/api/transactions/macrodroid` (retained for backward-compatibility during staged rollout)

### Authentication & Identification
- `userId` passed via query parameter (`?userId=<UUID>`), JSON payload, or `Bearer <JWT>` Supabase session header.
- Verified against `profiles.id` with `subscription_tier = 'PRO'` gating.

### Ingestion Logic
1. **Direct Extract**: Reads `merchant`, `amount`, and `source` if explicitly structured.
2. **AI Extraction Fallback**: If `merchant` or `amount` are absent, passes `raw_text` / notification body through `generateAIContent` in JSON mode (`modelType: "flash"`).
3. **Deterministic Sign Calculation**:
   - Outflow triggers: `saída`, `compra`, `pagamento`, `débito`, `spent`, `withdrawal`, `paid`, `charge`, `purchase`.
   - Inflow triggers: `entrada`, `crédito`, `recebida`, `reembolso`, `depósito`, `salary`, `payroll`.
   - Default: All card purchases/expenses default to negative outflow.
4. **Auto-Categorization**:
   - Matches merchant string against the user's registered rules table (`rules.keyword`).
   - Falls back to general/other user category if no specific rule matches.
5. **Database Persistence**: Writes to `tracker_expense` with UTC ISO timestamp.

---

## 2. Android Native Implementation (`NotificationListenerService` & `LegerBankSyncPlugin`)

### Architecture
1. **`LegerBankNotificationListenerService.java`**:
   - Extends Android's `NotificationListenerService`.
   - Dynamic user-monitored package matching from `SharedPreferences` (`"selected_bank_packages"`).
   - Zero-overhead asynchronous HTTP dispatch to `/api/transactions/device-push`.
2. **`LegerBankSyncPlugin.java`**:
   - Native Capacitor plugin providing `getInstalledApps()`, `getSelectedBankPackages()`, `setSelectedBankPackages()`, and `openNotificationAccessSettings()`.
   - Automatically prioritizes finance/banking apps while allowing full device app browsing.
3. **100+ Curated Banking & Fintech Registry (`src/lib/banking-apps-registry.ts`)**:
   - Curated packages, regions, and domains across Portugal, Spain, UK, Europe, US, and Brazil.

### Google Play Store & Legal Compliance Invariant
- **In-App Prominent Disclosure**: Prominently displayed in `DeviceSyncManager.tsx` before requesting permissions.
- **Zero-Storage Privacy Standard**: Raw push texts are processed in memory and discarded. OTPs, 2FA security codes, and personal chat notifications are strictly ignored.
- **100% Legal & Sanctioned**: Operates strictly via Google's official `NotificationListenerService` and `QUERY_ALL_PACKAGES` APIs. All uncertified raw NFC contactless chip reading is banned.

---

## 3. iOS Apple Shortcuts Protocol (iOS 17+)

Because Apple iOS strictly isolates apps from third-party notification drawers:
- **Trigger**: Personal Automation on *Apple Pay / Wallet Transaction* or *Bank SMS Receipt*.
- **Action**: "Get Contents of URL" executing `POST` to `https://leger-os.vercel.app/api/transactions/device-push?userId=<ID>` with JSON body `{"raw_text": "Shortcut Input"}`.
- **Execution Mode**: "Run Immediately" without user confirmation.

- Embedded inside:
  - `SystemSettingsModal.tsx` (Tab: `phone` / `Sync`)
  - `SystemConfigView.tsx` (Tab: `phone` / `Device Sync`)

- Features:
  - **Dynamic Scope Tabs**: `Finance & Banking (N)` and `All Installed Apps (N)`.
  - **Empty Detection Fallback**: Explains when 0 banking apps are recognized and routes to full app list.
  - **1-Tap Notification Permission Banner**: Direct link to Android's notification access screen.
  - **Interactive Ingestion Simulator**: Tests bank notification payloads with instant feedback.
