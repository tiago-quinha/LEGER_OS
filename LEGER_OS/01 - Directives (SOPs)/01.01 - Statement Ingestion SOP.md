# 01.01 - Statement Ingestion SOP

**Layer 1 Directive (SOP)**

## Objective
Extract, clean, categorize, and ingest monthly bank extracts (.pdf, .txt, .csv) into Supabase across any bank or language.

## Multi-Lingual Column & Sign Resolution Architecture
1. **Tier 1 - Mathematical Balance Delta Verification**:
   If a running balance column is present, `Delta = Balance[new] - Balance[previous]`.
   - `Delta < 0` => Transaction is an Outflow (Negative Amount, `-`).
   - `Delta > 0` => Transaction is an Inflow (Positive Amount, `+`).
2. **Tier 2 - Spatial Column Alignment**:
   PDF layout rendering detects column headers across languages (`Inflow`/`Entry`/`Crédito`/`Abono`/`Einnahmen`/`Entrées` vs `Outflow`/`Exit`/`Débito`/`Cargo`/`Ausgaben`/`Sorties`). Values under Outflow columns are assigned negative signs (`-`).
3. **Tier 3 - Multi-Lingual Keyword Engine**:
   Evaluates transaction line text against multi-lingual dictionaries (English, Portuguese, Spanish, French, German, Italian, Dutch) to resolve sign and categorization.

## Telemetry Counters & Ingestion Preview
- **Est. Start Balance**
- **Total Inflow (Entry)**: Sum & item count of positive transactions (`amount > 0`).
- **Total Outflow (Exit)**: Sum & item count of negative transactions (`amount < 0`).
- **Net Flow / Selected**: Selected vs total record counts and uncategorized badge.
- **Select All Header**: Interactive master checkbox for batch selection.

## Execution Workflow
1. Export `.txt` or `.pdf` bank statement into workspace or upload via Ingest tab on `/expenses`.
2. Execute ingestion script:
   ```bash
   python import_transactions.py
   ```
3. Activate or verify multi-lingual auto-sign trigger:
   ```bash
   python activate_auto_sign.py
   ```
4. Reconcile balance snapshots:
   ```bash
   python audit_balances.py
   ```
5. Regenerate vault notes:
   ```bash
   python build_full_vault.py
   ```
