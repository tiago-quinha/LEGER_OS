# 01.01 - Statement Ingestion SOP & Multi-Bank Engine Reference

**Layer 1 Directive (SOP)**

## Objective
Provide an ultra-fast, universal, multi-bank statement ingestion engine that deterministically parses CSV, TSV, and digital PDF statements across 14+ global banking standards with **zero AI token usage for free users**, while reserving multimodal vision and neural cleansing for PRO tier users.

---

## 1. Multi-Bank Ingestion Architecture (2-Layer Engine)

### Layer A: Deterministic Universal Ingestion (100% Free / Client-Side)
Located in `src/lib/csv-bank-parser.ts` and `src/components/ExpensesView.tsx`:

1. **RFC 4180 CSV / TSV Parsing (`parseUniversalCsv`)**:
   - Auto-detects delimiters (`,`, `;`, `\t`, `|`).
   - Strict double-quote handling (preserves apostrophes in brand names like `McDonald's`, `Sainsbury's`, `L'Oréal`).
   - Adaptive date parser: `YYYY-MM-DD`, `DD/MM/YYYY`, `MM/DD/YYYY`, `DD.MM.YYYY`, and compact numeric `YYYYMMDD` (Dutch ING).
   - Localized numbers: European comma decimals (`1.250,50`, `1 250,50`) vs US dot decimals (`1,250.50`).
   - Direction indicator column support (`Af Bij`, `Debit/Credit`, `D/C`, `CR/DR`, `Sign`, `Mutatiesoort`).

2. **Multi-Line Bank PDF Stream Parser (`parseMultiLineStatement`)**:
   - Handles stacked statement formats (e.g. Santander Portugal, CaixaBank, Millennium BCP) where each transaction spans consecutive lines (`Date`, `D. valor`, `Merchant`, `Amount`, `Balance`).
   - Text date localization across English, Portuguese, Spanish, French, and German (`19 jun. 2026`, `15 Aug 2026`).

3. **2D Spatial PDF Reconstructor (`/api/ingest/parse-pdf`)**:
   - Uses Y-coordinate row clustering (3px spatial tolerance) and X-column boundary projection to assemble tabular digital PDFs.

### Layer B: PRO Multimodal AI Ingestion (`/api/ingest/ai-parse`)
- **Scanned Image PDFs & Receipt Photos**: Multimodal vision parsing via Gemini 2.5 Pro / GPT-4o Vision for camera snapshots and flattened image PDFs with zero text characters.
- **AI Neural Cleanse**: Strips cryptic POS terminal strings into clean merchant names.
- **Custom API Key Support**: Free users can provide their own Gemini/OpenAI API key in System Config.

## 2. Tested & Verified Global Bank Matrix

| Region / Bank | Supported Formats | Quirks Handled |
| :--- | :--- | :--- |
| **Global Neobanks** (Revolut, Wise, N26) | CSV | Quoted titles, transfer fees, running balances, multi-currency |
| **Portugal** (CGD, Millennium BCP, ActivoBank, Santander, Novo Banco, BPI) | CSV, PDF, TXT | Semicolon delimiters, `Data Lançamento`, `Descritivo`, stacked PDF blocks |
| **United States** (Chase, BofA, Wells Fargo, Citi, Apple Card) | CSV, PDF | `MM/DD/YYYY` dates, `Posting Date`, internal commas in merchant names, accounting `(100.00)` |
| **United Kingdom** (Monzo, Barclays, HSBC, NatWest, Lloyds, Starling) | CSV, PDF | `Money In` / `Money Out`, subcategories, single quotes in store names |
| **Spain** (BBVA, CaixaBank, Santander ES, Sabadell) | CSV, PDF | `Fecha valor`, `Concepto`, `Importe`, `Saldo disponible` |
| **France** (BNP Paribas, Société Générale, Crédit Agricole, BoursoBank) | CSV, PDF | `Date opération`, `Libellé`, separate `Débit` and `Crédit` |
| **Germany / Austria** (Deutsche Bank, DKB, Commerzbank, Sparkasse) | CSV, PDF | Preamble metadata at top (`Kontonummer: ...`), `Buchungstag`, German decimals `1.500,00` |
| **Netherlands / Belgium** (ING, Rabobank, ABN AMRO, KBC) | CSV | Compact numeric `YYYYMMDD`, `Af Bij` direction indicator |
| **Italy** (Intesa Sanpaolo, UniCredit, Postepay) | CSV, PDF | `Data contabile`, `Descrizione operazione`, `Importo`, `Saldo` |
| **Nordics** (Swedbank, Nordea, SEB, Danske Bank) | CSV, PDF | `Bokföringsdatum`, `Text`, `Belopp`, `Saldo` |
| **Latin America** (Nubank, Itaú, Bradesco, BBVA México) | CSV | `Data`, `Descrição`, `Título`, `Valor`, `Identificador` |

## 3. Empty State & UX Guidelines

- **No Floating Tour Spotlights**: Ban full-screen tour spotlight overlays (`IngestSpotlightOverlay`) that point away from the current page.
- **Native In-Card Zero State**: Display the centered `PROJECTION ENGINE CALIBRATED` empty state card directly on the Dashboard with two prominent actions:
  - `[ UPLOAD STATEMENT ]` (routes directly to `/expenses?tab=ingest`)
  - `[ + ADD EXPENSE ]` (opens expense entry modal)

---

## 4. PostgREST Cache Invalidation Invariant
All database migrations or direct script insertions must execute:

NOTIFY pgrst, 'reload schema';
