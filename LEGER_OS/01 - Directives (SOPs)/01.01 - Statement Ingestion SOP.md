# 01.01 - Statement Ingestion SOP

**Layer 1 Directive (SOP)**

## Objective
Extract, clean, categorize, and ingest monthly Santander bank extracts into Supabase.

## Execution Workflow
1. Export `.txt` or `.pdf` bank statement into workspace.
2. Execute ingestion script:
   ```bash
   python import_transactions.py
   ```
3. Fix inverted transaction signs if required:
   ```bash
   python activate_auto_sign.py
   ```
4. Reconcile balance snapshots:
   ```bash
   python audit_balances.py
   ```
5. Regenerate vault notes:
   ```bash
   python build_full_vault.py
   ```
