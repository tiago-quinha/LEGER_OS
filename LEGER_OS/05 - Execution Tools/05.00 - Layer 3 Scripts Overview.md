# Layer 3 Execution Tools Overview

| Script Name | Function | Command |
| :--- | :--- | :--- |
| `import_transactions.py` | Parses Santander extracts into Supabase tracker_expense table. | `python import_transactions.py` |
| `audit_balances.py` | Reconciles account balance snapshots and updates account_balance table. | `python audit_balances.py` |
| `update_schema.py` | Updates PostgreSQL table schema via direct connection port 5432. | `python update_schema.py` |
| `detect_cycles.py` | Analyzes Deloitte paycheck cycle boundaries and days elapsed. | `python detect_cycles.py` |
| `forensic_audit.py` | Verifies transaction mathematical sign integrity. | `python forensic_audit.py` |
| `activate_auto_sign.py` | Flips inverted debit transaction signs. | `python activate_auto_sign.py` |
| `add_balance_table.py` | Adds account_balance table schema. | `python add_balance_table.py` |
| `add_income_table.py` | Adds income table schema. | `python add_income_table.py` |
| `add_new_categories.py` | Seeds default category records. | `python add_new_categories.py` |
| `debug_cycle_discrepancy.py` | Debugs discrepancy between cycle calculations. | `python debug_cycle_discrepancy.py` |
| `fix_years_import.py` | Fixes year parsing anomalies in historical extracts. | `python fix_years_import.py` |
| `import_all_history.py` | Batch imports all historical statement text files. | `python import_all_history.py` |
| `migrate_multi_tenant.py` | Migrates single-tenant schema to multi-tenant RLS. | `python migrate_multi_tenant.py` |
| `reconcile_v3.py` | V3 reconciliation engine for balance verification. | `python reconcile_v3.py` |
| `reimport_with_signs.py` | Re-imports statement records with corrected signs. | `python reimport_with_signs.py` |
| `seed_rules.py` | Seeds automated category mapping rules. | `python seed_rules.py` |
